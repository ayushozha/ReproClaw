How it works

Four steps, one email thread.

Each audit runs end-to-end without leaving the inbox. The dashboard is a window into the same work.

  1. 01

    Email a paper and a repo

    Send any arXiv URL plus a public GitHub link to audit@reproclaw.com. AgentMail picks the thread up.

  2. 02

    Claims are extracted

    The paper is parsed into atomic, falsifiable claims — hyperparameters, datasets, results, ablations — each tagged for verification.

  3. 03

    Code evidence is aligned

    Nia indexes the repository and resolves each claim to the exact file, function, and line that proves or contradicts it.

  4. 04

    The audit is emailed back

    You receive a reproducibility score, a verdict per claim, and the evidence excerpts inline — replying threads more questions back to the agent.
